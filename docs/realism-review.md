# Munnar Tea Estate scene

`realism-review.html` is the playable development scene for the [approved visual reference](art/munnar-approved-reference.png). The real-map page links to it as **New Munnar scene**. It reuses the game renderer, original Heritage motorcycle, rigged rider and free steering. The default view follows the rider approaching the paved-road/dirt-track fork. Touch steering, brake and accelerator controls, a route minimap, a delivery objective, and optional inspection views are available.

The central landscape uses NASA/USGS SRTM elevation sampled every 60 metres through Open Topo Data. It is regional relief, not a road survey. The paved route and dirt loop are authored game routes; both ends of the dirt loop connect to the paved route. The dirt track curves forward from the junction, with grade limited to make it rideable. The tea stall accepts the delivery when the rider stops nearby. Distant mountain layers are authored scenery with forest canopy cards. Existing full real maps still use OpenStreetMap coordinates; this contained scene does not replace them.

Tea hedges follow elevation contours generated with marching squares. Each detailed plant combines 230 curved alpha foliage sprays with low branching stems. The original generated tea atlas supplies visible veins, pointed leaf shapes and fresh shoots; bark uses the scanned CC0 tree material. The supplied photos are visual references and are not shipped as textures. Denser foliage at the hedge edges partly hides the woody stems. Narrower contour spacing, continuous plantation soil, gravel shoulders, drainage, worn markings, an open tea stall and two rigged tea pickers support the reference layout.

Detailed plants follow the camera through a spatial grid, with up to 384 nearby plants on desktop or 192 in viewports narrower than 1,000 pixels. More distant tea uses side and top textures baked from the same model. Both tea and forest bakes keep linear HDR radiance in half-float GPU textures; the scene applies its tone mapping once, avoiding clipped, washed-out distant foliage. Warm directional sunlight and reduced ambient environment light keep tea green, soil warm and shadows readable. The SSAO normal override ignores foliage alpha, so this scene uses alpha-tested directional shadows instead. The Detail control adjusts rendering resolution. Phone frame rates still need measurement on real devices.

External asset sources are recorded in `public/realism/LICENSE.txt`. To refresh source assets, run `python scripts/import-realism-assets.py` (Pillow required), `blender --background --python scripts/optimize-realism-tree.py`, and `python scripts/compress-realism-textures.py`. Elevation can be refreshed with `python scripts/import-munnar-elevation.py`. The original tea atlas is tracked as `public/realism/tea-foliage-atlas.png`.

Validation: `npm run build`, `npm run check`; serve the built site on port 4173 and run `node scripts/check-realism-review.mjs`. The browser check verifies the rigged rider, terrain provenance, connected endpoints, dirt-track grade, finite foliage geometry and HDR baking; moves the detailed foliage farther along the route; exercises the camera controls, keyboard driving, real touch acceleration and delivery completion; and captures the initial approved-composition view, landscape, tea detail, rider, roadside and mobile screenshots.
