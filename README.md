# MudMeals

Third-person motorcycle delivery game built with Three.js, TypeScript, and Vite.

## Current milestone

Milestone 1 — Driving Prototype.

Goal: make riding feel responsive and enjoyable before adding delivery, economy, or large-world systems.

## Run locally

```bash
npm install
npm run dev
```

Production validation:

```bash
npm run build
npm run preview
```

## Controls

- W / Arrow Up: accelerate
- S / Arrow Down: brake / reverse
- A / Arrow Left: steer left
- D / Arrow Right: steer right
- Space: stronger brake
- R: reset bike
